# Average-RPG-Pyxel

## Descrição do Jogo
Avarage RPG Pyxel é um RPG de turno single-player com foco em batalhas contra chefes e escolhas estratégicas.Com o desenvolvimento em Python, utilizando a biblioteca do Pyxel para a interface e os gráficos.

## Integração em STEAM

Desenvolver o Average RPG Pyxel foi alem de escrever linha de codigo e sim uma verdadeira experiencia. Foi um verdadeiro laboratório onde consegui juntar varias areás, aplicando na práticao conceito de STEAM

Ciência (S): Uso de probabilidades e geração de números aleatórios (RNG) para garantir golpes críticos, esquivas e espólios imprevisíveis, tornando cada partida única.

Tecnologia (T): Domínio do ciclo de vida do jogo (update e draw) construído do zero com Python e a engine retro Pyxel.

Engenharia (E): Estruturação do código através de uma Máquina de Estados para transitar de forma limpa entre menus, combates e ecrãs de fim de jogo.

Artes (A): Criação manual de toda a pixel art com paleta restrita e programação de efeitos sonoros gerados diretamente por código, sem ficheiros de áudio externos.

Matemática (M): Criação de fórmulas de balanceamento para escalonar a vida e o dano dos inimigos, além de gerir recursos vitais como Stamina, Mana e curas percentuais.
